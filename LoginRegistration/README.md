# LoginRegistration Xcode Project

This project follows the professor's LoginKit architecture while keeping the personalized interface and registration extension.

Open `LoginRegistration.xcodeproj`, select the shared **LoginRegistration** scheme and an iPhone simulator, then press Command-R or Command-U.
